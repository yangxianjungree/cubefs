# BlobStore 纠删码子系统概述

## 模块定位

BlobStore (`blobstore/`) 是 CubeFS 的纠删码 (Erasure Coding) 存储子系统，用于冷数据的高可靠低成本存储。它独立于副本存储子系统，可以单独部署或与副本存储共存。

## 组件架构

```
Client / ObjectNode / LcNode
    │
    ▼
┌─────────────┐     ┌──────────────┐
│   Access    │────▶│    Proxy     │
│ (数据网关)   │     │ (代理/分配)   │
└──────┬──────┘     └──────┬───────┘
       │                    │
       ▼                    ▼
┌─────────────┐     ┌──────────────┐
│  BlobNode   │     │ ClusterMgr   │
│ (数据存储)   │     │ (集群元数据)   │
└─────────────┘     └──────────────┘
       ▲
       │
┌──────┴──────┐
│  Scheduler  │
│ (后台调度)   │
└─────────────┘
```

## 核心组件

| 组件 | 职责 |
|------|------|
| **Access** | 数据访问网关，提供 Put/Get/Delete/Alloc API |
| **ClusterMgr** | 集群元数据管理，Raft 保证一致性 |
| **BlobNode** | 数据存储节点，管理 Chunk 和 Shard |
| **Scheduler** | 后台任务调度（数据修复、均衡、巡检） |
| **Proxy** | 代理层（空间分配、缓存、负载均衡） |
| **ShardNode** | 分片管理节点，Raft 保证分片元数据一致性 |
